# FX Options

An independent project on FX options pricing, modelling, numerical methods, and quantitative research. It will start with vanilla options in Python, then use that foundation to study exotic payoffs, model calibration, and hedging.

Planned numerical work includes Monte Carlo simulation and finite-difference methods. Research experiments will use public references and synthetic or publicly available data.

The project is at the setup stage. See [roadmap.md](roadmap.md) for planned work and [progress.md](progress.md) for milestones.

## Repository layout

- `src/` holds reusable models and pricing methods.
- `tests/` holds numerical and behavioural checks.
- `notebooks/` holds exploratory analysis and reproducible experiments.
