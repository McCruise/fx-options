# Roadmap

1. Define FX quote and payoff conventions and test a vanilla call payoff.
2. Implement and test Garman–Kohlhagen prices for vanilla calls and puts, then add Greeks.
3. Compare Monte Carlo and finite-difference methods against analytical benchmarks.
4. Explore volatility smiles, calibration, barrier options, and hedging through reproducible experiments.
5. Introduce C++ for performance-sensitive work when profiling supports it.

Revisit the sequence after each exercise based on demonstrated programming and testing skills.
